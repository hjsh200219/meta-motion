# 미술감독 채점 — 결함이 없는 것과 잘 만든 것은 다르다

lint·check·`motion.py check` 를 통과해도 영상이 밋밋할 수 있다. 이 단계는 별도 에이전트가 렌더 장면을 보고 점수를 매기고, 약한 장면을 다시 만들게 한다.
착안: script-to-motion `references/elevate.md` (https://github.com/kstost/script-to-motion, MIT © 2026 kstost). 기준은 이 스킬의 카드 「자세히」 사양과 템플릿에 맞췄다.

## 언제

- **단독 HyperFrames 영상**(사용자 기본값 6번 ①)에서 첫 렌더가 검사를 모두 통과한 뒤에 묻지 않고 한다. 사용자가 「밋밋해」·「아쉬워」라고 한 구간에도 한다.
- **하지 않는 곳**: 릴스 자동 발행(② `gen-motion-reel.mjs` 무인 잡), 사용자가 고쳐 달라고 한 작은 수정(그때는 검사만 한다).

## 1. 감독에게 줄 그림

프레임마다 시각으로 이동해 찍은 정지 화면이다. 실제 렌더와 같은 그림이며, 대조 시트(`contact-sheet.jpg`, 장이 많으면 `contact-sheet-1.jpg`·`-2.jpg` 처럼 여러 장)가 함께 생긴다. `--composition` 에는 루트의 장면 host id(`data-composition-id`)를 준다. 세 명령은 2026-11-11 실제 세로 프로젝트 사본에서 돌려 확인했다. Gemini 설명은 끈다(`GEMINI_API_KEY=` 비움).

```bash
HF="npx --yes hyperframes@0.8.162"
GEMINI_API_KEY= $HF snapshot <프로젝트> --frames 16 -o <프로젝트>/review/r1/all                 # 영상 전체
GEMINI_API_KEY= $HF snapshot <프로젝트> --composition <장면id> --frames 4 -o <프로젝트>/review/r1/<장면id>   # 장면마다
GEMINI_API_KEY= $HF snapshot <프로젝트> --range 7.0,8.4 --frames 6 -o <프로젝트>/review/r1/t-7.0      # 전환·카메라 이동
```

함께 줄 것은 장면마다 쓴 카드 코드와 그 「자세히」 사양(`motion.py show` 출력), 템플릿 id 와 `palette`, `script.txt` 다. 코드·로그는 주지 않는다.
2라운드부터는 이전 라운드 시트도 준다. 앞판과 비교하라는 것이 아니라, 같은 화면에 장식만 덧댔는지 보라는 것이다.

## 2. 채점 — 장면마다 세 축, 1~5점

점수마다 근거 프레임(파일 이름의 시각)을 붙인다. 척도는 절대 기준이며 앞판과 비교하지 않는다.

- 3: 카드 사양대로 깔끔하다
- 4: 장면마다 「볼거리 한 번」이 또렷하고 리듬이 살아 있어 따로 봐도 좋다
- 5: 다시 보고 싶다

- **연출**
  - 카드의 `[장면 순서]`·`[볼거리 한 번]`이 실제 그림에 보이나.
  - 말하는 순간에 그 그림이 나오나.
  - 인트로가 열고 아웃트로가 닫나(로고·한 줄 마무리·여운).
  - 장면 사이가 이어지나(잘린 듯 끊기지 않나).
  - 같은 구도가 오래 이어지지 않나.
- **그래픽 디자인**
  - 템플릿 색이 제자리에 배선됐나(`band`·`accent` 는 핵심 한두 단어·`accent_shape`·`stroke`).
  - 위계: 제목 > 자막 > 보조.
  - 자막 가독성: 줄 나눔·행잉 인덴트·안전 영역·대비.
  - 글자 크기·여백이 화면 비율에 맞나.
  - `[하지 말 것]` 위반이 없나.
- **모션**
  - 이징(기계적인 선형 금지).
  - 순차 등장(stagger)과 예비 동작·여운.
  - 정지 구간: 말이 이어지는데 그림이 멈춘 곳.
  - 한 프레임 튐·기본 상태 깜빡임(전환 시트에서 찾는다).

템플릿의 제목 띠·자막 스타일은 사용자가 고른 형식이다. 그 자체를 감점하지 않는다. 감점은 그 형식 안에서 덜 다듬은 것에만 준다.

## 3. 감독이 돌려줄 것

- 장면별 세 축 점수와 근거 프레임
- `[하지 말 것]`·사용자 기본값(인트로·아웃트로·행잉 인덴트·안전 영역) 위반 목록
- 고칠 것 6~10개(효과가 큰 순서, 장면 id·무엇을 어떻게)

## 4. 다시 만들기와 반복

- 약한 장면은 장식을 덧대지 말고 카드 사양에서 다시 짠다. 같은 화면에 층만 더한 라운드는 친 셈하지 않는다. 효과를 어떻게 짤지 모르겠으면 `motion.py technique <단어>`(cokacmotion)에서 기법을 찾는다. 기술만 가져온다.
- 고친 뒤 lint·check·`motion.py check` 를 다시 통과시키고, 같은 snapshot 명령을 `review/r2/…` 로 다시 찍어 감독에게 다시 준다.
- 모든 장면이 세 축 모두 4 이상이 되거나 3라운드가 되면 멈춘다. 렌더 비용 때문에 3라운드가 상한이다.
- 보고에 장면별 점수를 처음 → 마지막으로 적고, 4에 못 미친 장면이 남았으면 이유를 적는다.
- 감독 에이전트를 띄울 수 없으면 같은 기준으로 직접 채점하되 따로 적는 단계로 한다. 「설명할 수 있는 화면」이 좋은 화면인 것은 아니다.
